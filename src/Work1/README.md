一、实验要求

1.使用 uv 创建项目级虚拟环境（.venv），避免全局污染。

2.采用 src 布局，分离配置、物理逻辑与视图，提升可维护性。

3.基于 Taichi 框架驱动 GPU 并行计算，实现大规模粒子群引力模拟。

4.代码推送至 GitHub，编写 README.md 并附演示效果。

二、实验思路与代码设计

1.环境与结构：uv 初始化项目，src/Work0/ 下建立 config.py（参数）、physics.py（GPU 核函数）、main.py（入口与渲染）。

2.物理逻辑：在 GPU 显存中定义粒子位置/速度场；@ti.kernel 并行更新引力、阻尼、边界反弹，完全不依赖视图。

3.视图交互：main.py 初始化 GUI，获取鼠标位置，驱动物理更新，将 GPU 数据转 numpy 绘制粒子。

4.运行：uv run -m src.Work0.main 启动，.gitignore 排除 .venv 等。

三、实验结果

1.弹出窗口显示数千至万级天蓝色粒子，移动鼠标时粒子群平滑跟随，边界反弹与阻尼效果明显。

2.GPU 加速保障实时交互，低帧率时可调小粒子数量优化。

3.演示 GIF 已附在 README.md 中，展示交互效果。

四、实验收获

1.掌握了 uv 虚拟环境与 src 工程化布局，增强项目可维护性。

2.理解了 Taichi 的 GPU 并行编程模型，可轻松驱动万级粒子物理模拟。

3.深化了配置、逻辑、视图三层分离的设计思想，便于后期调参与扩展。

4.熟悉了 Git 仓库管理与规范文档编写，为后续协作奠定基础。
