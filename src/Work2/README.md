实验二 —— 3D 坐标变换与透视投影

一、实验要求

1.实现模型、视图、投影三个 MVP 核心矩阵，完成三角形顶点的 3D→2D 变换。

2.基于 Taichi 框架渲染线框三角形，支持键盘控制旋转。

3.选做：升级为 3D 立方体；补充：实现双姿态旋转插值过渡。

二、实验思路与代码设计

1.矩阵推导：

get_model_matrix：绕 Z 轴旋转矩阵（角度转弧度）。

get_view_matrix：将相机位置平移到原点的平移矩阵。

get_projection_matrix：先构造透视挤压矩阵（M_persp2ortho），再组合正交投影的平移与缩放。

2.渲染管线：顶点存储在 Taichi field 中，compute_transform 核函数逐顶点计算 MVP = proj @ view @ model，经透视除法和视口变换映射到屏幕坐标，GUI 绘制线框。

键盘交互：A/D 键控制旋转角度增量。

3.选做实现：

立方体：定义 8 顶点和 12 条边索引，循环绘制边。

插值：构造两个不同旋转角度的模型矩阵，在主循环中利用线性插值（Lerp）生成中间矩阵，实现平滑过渡。

三、实验结果

1.必做题：窗口显示彩色三角形（红绿蓝边），按 A 顺时针、按 D 逆时针绕 Z 轴旋转，透视效果正确。

2.选做一：成功绘制 3D 立方体线框，旋转时立体感明显，各边比例协调。

3.选做二：两个姿态间的插值动画平滑连续，无跳变，展示了变换的连贯性。

四、实验收获

1.环境修复：在大模型指导下修复了本地 conda 损坏问题，成功配置 cg_env 环境，保障实验顺利进行。

2.矩阵推导演练：亲手实现了 MVP 三个核心矩阵，尤其是透视投影中平截头体挤压与正交归一化的数学推导，加深了对 3D 渲染管线的理解。

3.细节把控：特别注意了角度弧度转换、zNear/zFar 取负值以及矩阵右乘顺序，这些细节是正确渲染的关键。

4.扩展实践：通过立方体绘制和旋转插值，掌握了三维线框几何体的构建方法及姿态过渡技巧，为后续复杂 3D 场景开发积累了经验。

5.交互反馈：键盘控制实时调节旋转角度，操作直观，验证了变换的实时性。
