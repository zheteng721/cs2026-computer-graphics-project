实验三 —— 贝塞尔曲线

专业：24级计算机班

学号：202411081113

一、实验要求

1.理解贝塞尔曲线几何意义，用 De Casteljau 算法递归计算曲线坐标。

2.实现光栅化：将浮点坐标映射为像素，点亮帧缓冲区。

3.鼠标左键添加控制点，按 C 清空，实时显示控制多边形和绿色曲线。

4.利用 GPU 并行加速，避免逐像素跨 PCIe 通信，保持高帧率。

5.选做：添加反走样优化与 B 样条曲线切换功能。

二、实验思路与代码设计

1.数据结构：预分配 GPU 缓冲区 pixels（800×800）、curve_points_field（1001 个采样点）、gui_points（最多 100 个控制点），采用对象池技巧避免动态内存分配。

2.De Casteljau 算法：纯 Python 递归函数，对给定 t 反复线性插值直到单点。

3.绘制流程：CPU 端批量计算所有曲线点，通过 from_numpy 一次性上传至 GPU；@ti.kernel 并行映射为像素坐标并点亮绿色。控制点与控制多边形由 canvas API 绘制。

4.选做实现：

反走样：对每个像素进行多点采样（超采样）或边缘模糊处理，减少锯齿。

B 样条曲线：实现三次均匀 B 样条算法，按 B 键在贝塞尔与 B 样条间切换。

三、实验结果

1.窗口显示黑色背景，鼠标左键点击依次添加红色控制点（最多 100 个），自动绘制灰色控制多边形。

2.控制点 ≥2 时生成绿色贝塞尔曲线，曲线平滑跟随控制点变化；按 C 键清空全部。

3.选做功能：按 B 键可切换至三次 B 样条曲线，曲线更平滑且具备局部支撑性；反走样处理后边缘无明显锯齿，显示质量明显提升。

四、实验收获

1.算法深化：亲手实现 De Casteljau 递归插值，理解了贝塞尔曲线的几何生成原理；通过 B 样条扩展，进一步认识了不同曲线表示法的特点与适用场景。

2.GPU 并行编程：掌握了 Taichi 中 @ti.kernel 并行绘制与批量数据上传（from_numpy）策略，避免逐像素跨 PCIe 通信，真正实现了高性能实时渲染。

3.交互设计：熟练处理鼠标点击、键盘事件，以及对象池在动态控制点数量下的应用技巧。

4.反走样实践：通过超采样或边缘模糊方法优化光栅化质量，直观感受到抗锯齿对视觉体验的提升。
