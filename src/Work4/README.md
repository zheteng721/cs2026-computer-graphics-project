一、实验要求

1.理解局部光照原理（环境光、漫反射、镜面高光），掌握三维空间向量运算。

2.使用 Taichi 实现光线投射，渲染球体与圆锥，并完成深度测试（最近交点遮挡）。

3.编写 Phong 着色器，并通过 UI 滑块实时调节 Ka、Kd、Ks、Shininess 参数。

4.选做：升级为 Blinn-Phong 模型，并实现硬阴影（Shadow Ray）。

二、实验思路与代码设计

1.场景构建：在 @ti.kernel 中对每个像素发射射线；定义 intersect_sphere 和 intersect_cone 函数求交，并比较最近距离实现深度竞争。

2.着色流程：在最近交点处计算法线 N、光线方向 L、视线方向 V 和反射方向 R，按 Phong 公式累加环境光、漫反射、高光，并 clamp 输出。

3.交互 UI：使用 ti.ui 创建控制面板，四个滑块绑定全局参数字段，实时更新渲染结果。

4.选做实现：

Blinn-Phong：计算半程向量 H = normalize(L+V)，用 N·H 替代 R·V，高光边缘更柔和。

硬阴影：在交点处向光源发射阴影射线，若中途击中其他物体则只保留环境光。

三、实验结果

1.必做题：窗口左侧显示红色球体，右侧显示紫色圆锥，遮挡关系正确；滑块调节各参数时，高光、漫反射、环境光实时变化，交互流畅。

2.选做：替换为 Blinn‑Phong 后，高光区域边缘明显更柔和、自然；硬阴影使圆锥在球体表面投射出清晰边缘的阴影，增加了场景真实感。

四、实验收获

1.必做题收获：完成了 Taichi 环境与 GPU 渲染框架搭建，实现了光线追踪基础流程。程序渲染球体与圆锥，采用 Phong 模型实现漫反射与高光，滑块可实时调节参数，掌握了光照计算原理。

2.选做题收获：将 Phong 升级为 Blinn‑Phong 并实现硬阴影，高光更柔和自然，阴影清晰。理解了半程向量计算与阴影检测原理。

3.性能与细节：注意向量归一化、max(0, N·L) 截断和颜色 clamp，避免常见渲染错误。

4.模型对比认识：Phong 高光边缘锐利，大入射角易断裂；Blinn‑Phong 高光呈“光晕状”，大入射角仍平滑过渡，更接近真实材质。
