实验五 —— 光线追踪

一、实验要求

1.理解光线投射与光线追踪的区别，掌握 Whitted 风格全局光照（阴影+镜面反射）。

2.构建含无限平面（棋盘格）、红色漫反射球和银色镜面球的场景。

3.使用迭代循环代替递归实现光线弹射，支持硬阴影和最多 5 次反射。

4.UI 交互：动态调节光源位置和最大弹射次数，实时观察阴影移动与镜面反射效果。

5.选做：实现抗锯齿（每个像素多点采样平均）。

二、实验思路与代码设计

1.场景定义：在 @ti.kernel 中对每像素发射主射线；scene_intersect 函数遍历球体和平面的求交，返回最近交点、法线、材质 ID 和颜色（平面用坐标奇偶性生成棋盘格）。

2.光线迭代：用 for bounce in range(max_bounces) 循环追踪路径。维护 throughput 能量衰减和 final_color：

3.击中镜面球：沿反射方向更新光线起点（加法线偏移防自相交），throughput 乘反射率（0.8），继续循环。

4.击中漫反射体：发射阴影射线检测遮挡，计算环境光 + 漫反射（若不在阴影中），累加后 break。

5.UI 控制：滑块调节光源 (X,Y,Z) 和 Max Bounces（1~5），实时更新。

6.选做（抗锯齿）：在每个像素内进行 4~8 次随机抖动采样，主射线方向微偏，将各样本颜色平均后输出，平滑物体边缘锯齿。

三、实验结果

1.必做题：窗口显示带棋盘格地面的三维场景，左侧红色漫反射球，右侧银色镜面球。移动光源时阴影平滑移动；调节弹射次数：1 次时无镜面反射，3 次以上右侧镜面球清晰反射出左侧红球和棋盘格，反射次数越多，反射内容越丰富。

2.选做：开启抗锯齿后，物体边缘和棋盘格线条的锯齿明显减少，画面更平滑自然，整体视觉质量提升。

四、实验收获

1.递归转迭代：理解了 GPU 不适合递归，采用循环迭代追踪光线，成功模拟了多次镜面反射，掌握了 Whitted 风格的核心流程。

2.精度避坑：深刻体会到阴影自相交（Shadow Acne）问题的成因，通过法线方向偏移 1e-4 成功解决，强化了数值稳定性意识。

3.实时交互：动态调节光源与弹射次数，直观感受镜面反射次数对画面复杂度的影响，理解光线追踪的计算量与画质权衡。

4.抗锯齿实践：通过多点采样平均，掌握了常见抗锯齿的简单实现，提高了渲染图像质量。
