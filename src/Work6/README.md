实验六 —— 可微渲染

一、实验要求

1.理解可微光栅化原理，掌握软光栅化（Sigmoid 边缘概率）解决梯度消失的方法。

2.基于 PyTorch3D，从多视角剪影图像反推并优化三维网格顶点坐标。

3.引入拉普拉斯平滑、边长一致性和法线一致性三大正则化损失，防止网格崩坏。

4.可视化优化过程，保存中间状态网格文件。

5.选做：联合纹理优化，同时拟合 RGB 图像与顶点颜色。

二、实验思路与代码设计

1.环境与数据：使用 PyTorch3D 框架，加载 cow.obj 目标模型并归一化；设置 20 个环绕视角渲染目标剪影图作为 Ground Truth。

2.可微渲染：采用 SoftSilhouetteShader 软光栅化器，通过 Sigmoid 函数在三角形边缘产生平滑概率过渡，使边界像素具有非零梯度。

3.优化流程：

初始化一个二十面体球（ico_sphere(4)）作为源网格，顶点偏移量 deform_verts 设为可微参数。

每轮迭代：计算形变后网格的预测剪影，与目标剪影计算 MSE Loss；叠加拉普拉斯平滑、边长惩罚、法线一致性三项正则化损失；使用 SGD 优化器更新顶点偏移。

正则化作用：防止顶点为迎合投影而交叉重叠，保持网格光滑与物理合理性。

4.选做（纹理优化）：将 SoftSilhouetteShader 替换为 SoftPhongShader，不仅拟合剪影，还拟合多视角 RGB 图像，同时优化顶点坐标与顶点颜色（或纹理贴图）。

三、实验结果

1.必做题：球体经过约 300 轮迭代，逐渐形变为奶牛形状。初始球体（Epoch 0）呈圆形剪影；中期（Epoch 100~200）头部、四肢雏形显现；最终（Epoch 300）剪影与目标高度吻合，网格光滑无尖刺。中间状态 .obj 文件保存完整，可用 MeshLab 查看三维形变过程。

2.选做：引入 RGB 拟合后，网格不仅形状准确，还具备与目标模型一致的颜色分布，视觉效果更真实。

四、实验收获

1.可微渲染认知：理解软光栅化通过 Sigmoid 产生梯度，使顶点即使位于像素外部也能获得引导，是逆图形学成功的关键。

2.正则化价值：单纯依靠剪影 Loss 会导致网格变为“刺猬”，三大正则化项缺一不可，深刻体会到先验约束在优化问题中的决定性作用。

3.框架实践：掌握了 PyTorch3D 的完整工作流（数据加载、多视角渲染、可微优化、模型保存），为后续三维重建任务打下基础。

4.扩展思路：纹理优化实验进一步理解了联合优化形状与外观的可能性，拓展了可微渲染的应用视野。
