





实验七 —— 质点-弹簧系统

一、实验要求

1.使用 Taichi 构建 20×20 布料质点-弹簧系统，实现重力、阻尼和结构弹簧力。

2.分别实现显式欧拉、半隐式欧拉和隐式欧拉（定点迭代）三种数值积分方法，对比稳定性。

3.通过 GGUI 交互面板实时切换积分方法、暂停/恢复、重置布料。

4.选做：补充剪切弹簧和弯曲弹簧，观察布料形态变化。

二、实验思路与代码设计

1.数据结构：用 ti.Vector.field 存储质点位置、速度、受力；预分配弹簧对和长度场；is_fixed 标记两个角点为固定点。

2.初始化拆分：将位置、弹簧、渲染索引分别放在三个 @ti.kernel 中，在 Python 侧顺序调用，保证 GPU 同步。

3.受力计算：在 @ti.func 中实现重力、阻尼和弹簧力（ti.atomic_add 累加），该函数会被内联到各积分 kernel 中，减少开销。

4.积分器实现：

显式欧拉：用旧速度更新位置，再用旧力更新速度，极易发散。

半隐式欧拉：先更新速度（钳制上限），再用新速度更新位置，稳定性较好。

隐式欧拉：使用定点迭代（3 次）近似求解未来状态，阻尼最强，最稳定。

5.UI 交互：三个按钮切换积分方法（自动重置布料）；暂停/恢复和重置按钮；3D 场景支持鼠标拖拽视角。

3.选做（剪切+弯曲弹簧）：在 init_springs 中增加对角线相邻点（剪切弹簧）和相隔一个点的连接（弯曲弹簧），并对应修改弹簧长度存储；在 compute_forces_on 中无需改动，因为弹簧力计算已通用。

三、实验结果

1.必做题：初始布料水平悬垂，两个角固定，受重力自然下垂。显式欧拉在默认参数下数帧内爆炸（质点飞出）；半隐式欧拉稳定，布料呈现逼真的起伏和摆动；隐式欧拉同样稳定但运动更“粘滞”，阻尼感明显。交互面板可实时切换，切换后重置为初始状态；暂停/恢复控制模拟进程，重置恢复平整布料。

2.选做（补充剪切与弯曲弹簧后）：布料抗剪切和抗弯曲能力增强，褶皱更细腻，边缘更挺括，动态行为更接近真实织物（如风中的旗帜），相比仅有结构弹簧时更不易过度拉伸变形。

四、实验收获

1.积分方法对比：直观体会显式欧拉对时间步长极其敏感（极易爆炸），半隐式欧拉是性价比最高的选择，隐式欧拉虽稳定但计算量大且过度阻尼，这为实际工程选型提供了感性认识。

2.GPU 编程优化：掌握了将多个计算步骤合并到单个 @ti.kernel 以最小化启动开销；使用 @ti.func 内联函数减少 GPU 调用；ti.atomic_add 解决并行写入冲突。

3.物理模拟调试：速度钳制是防止数值爆炸的重要保障；弹簧初始长度需正确计算；固定点设置影响整体形态。

4.扩展能力：通过补充剪切/弯曲弹簧，理解了不同弹簧类型对布料刚度和外观的影响，为后续更复杂的变形体模拟打下基础。
