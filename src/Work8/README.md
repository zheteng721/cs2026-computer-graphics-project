一、实验要求

1.理解 SMPL 参数化人体模型，掌握模板网格、形状参数、姿态参数、关节回归器和蒙皮权重之间的关系。

2.分阶段提取并可视化 LBS 四个关键中间量：(a) 模板网格与单关节权重；(b) 形状校正后的网格与关节；(c) 姿态校正偏移量；(d) 最终 LBS 蒙皮结果。

3.手写实现 LBS 完整流程，并与官方前向计算结果进行数值对比验证（平均绝对误差和最大绝对误差）。

4.生成总对比图，并思考各阶段的物理意义。

二、实验思路与代码设计

1.环境与数据：使用 smplx 库加载 SMPL_NEUTRAL.pkl 模型，安装 chumpy 兼容层处理旧版 pickle 格式。

2.阶段分离实现：在 compute_manual_lbs() 函数中按顺序计算：

(a) 模板顶点 v_template 和蒙皮权重 lbs_weights，选取指定关节（如 joint_id=18）提取权重标量用于热力图。

(b) 通过 blend_shapes 应用形状参数 betas 得到 v_shaped，再用 vertices2joints 回归关节位置 J。

(c) 将轴角姿态（global_orient + body_pose）转为旋转矩阵，构造 pose_feature = R - I，通过 posedirs 线性映射得到姿态偏移 pose_offsets，加到 v_shaped 得到 v_posed。

(d) 调用 batch_rigid_transform 计算关节全局变换矩阵 A，用蒙皮权重加权平均得到每个顶点的 4×4 变换矩阵，应用于 v_posed 的齐次坐标，得到最终顶点 verts。

3.可视化：使用 matplotlib 绘制 3D 网格，通过顶点标量（权重或偏移量范数）映射颜色；同时生成全关节主导权重分布图。最终将四个阶段排列为 2×2 对比图。

4.一致性验证：用相同的 betas、global_orient、body_pose 调用官方 model.forward()，与手写结果逐顶点比较，输出 summary.txt 记录误差。

三、实验结果

1.成功加载 SMPL 模型，输出顶点数（6890）、面片数（13776）、关节数（24）、betas 维度（10）。

(a) 模板权重热力图：选定关节（如右肩）的权重在对应区域呈红色（权重接近 1），远离区域呈蓝色（权重接近 0），清晰展示了皮肤绑定区域。

(b) 形状校正：设置非零 betas 后，网格体型明显变化（如变胖或变高），关节位置也随之偏移，v_shaped 与 v_template 有明显差异。

(c) 姿态校正：抬手、弯肘等姿态下，pose_offsets 在关节弯曲处（肘、膝、肩）产生较大偏移量，颜色突出显示，体现姿态相关的局部几何修正。

(d) LBS 结果：最终网格呈现自然姿态，关节位置正确，皮肤变形平滑，无明显撕裂或穿插。

2.一致性验证：手写 LBS 与官方前向结果的平均绝对误差约为 1e-6~1e-7 量级，最大误差约为 1e-5 量级，完全一致。

3.对比图清晰展示了从模板到最终姿态的完整演变过程。

四、实验收获

1.深入理解 LBS 管线：亲手逐阶段实现，明确了形状参数和姿态参数对网格的独立影响，以及蒙皮权重在最终变换中的线性组合作用。

2.关节位置依赖形状：形状改变后关节位置重新回归，而非固定不变，符合人体真实变形规律。

3.姿态校正的必要性：仅靠骨骼刚体旋转会导致局部皮肤塌陷或膨胀，pose_offsets 有效补偿了这类误差，提升变形真实感。

4.工程实现细节：掌握了 smplx 的 API 使用，处理了 posedirs 转置问题，并利用 torch 实现批量矩阵运算，为后续人体姿态估计、动画合成等任务打下基础。

5.数值验证意识：通过对比官方实现验证手写正确性，培养严谨的工程习惯。
